# Engine chart-response fixture

`sibly-1776.json` is the **real engine output** for the US Sibly chart — the
wire-format ground truth for `src/features/chart/config/engine-types.ts` and
the `buildConfiguration` tests. Generated by the engine, never hand-edited.

- **Chart:** US Sibly — `datetime: 1776-07-04T22:10:00Z`, `latitude: 39.9526`,
  `longitude: -75.1652`, `elevation: 0`, `house_system: "Whole Sign"`,
  `zodiac_system: "Tropical"` (the serde-exact spellings), plus the FFI
  defaults: mean lunar node, mean Lilith, traditional fortune method, default
  body set (10 planets + Mean Node), no stars.
- **Generator:** `crates/kairos-core/examples/dump_chart_response.rs` in the
  engine repo — replicates the body of `kairos_calculate_chart`
  (`crates/kairos-ffi/src/functions.rs`) calling kairos-core directly (no FFI
  session). Output is the `ChartCalculationResponse` wire shape.
- **Engine branch / commit:** `feat/chart-wheel-ts-codegen`, base
  `f46672d8c052edbf466202d27744caa9262ebcae` (the example file itself lands on
  the same branch with this task).
- **Ephemeris:** kairos-ios bundled set
  (`kairos-ios/kairos-swift/Resources/Ephemeris` — needs the `_12` 600-year
  block covering 1776).
- **Generated:** 2026-08-14, Task 7 (chart-wheel-foundation).

Regenerate (from the engine worktree):

```sh
cd /Users/benatky/armillary/repos/kairos-engine/.worktrees/chart-wheel-ts-codegen
cargo run --example dump_chart_response -p kairos-core -- \
  /Users/benatky/armillary/repos/kairos-ios/kairos-swift/Resources/Ephemeris \
  > /Users/benatky/armillary/repos/kairos-expo/.worktrees/chart-wheel-foundation/src/features/chart/fixtures/engine/sibly-1776.json
```

Known nondeterminism: `chart_metadata.chart_id` is a fresh UUID every run
(`Chart::new` generates it, same as the FFI path) — regenerating always diffs
that one field. Everything else is a deterministic function of the ephemeris.
