# kairos-expo

Kairos, rebuilt in Expo. The journal is the product; the sky is its index.

Two tabs and a search: the journal (home — the daily glance), the chart (the interactive experience), and global search as the separated bar accessory. iOS + Android; web parked.

Design seed, decisions, and the staged build walk: `zojercommons/projects/kairos/specs/2026-08-05-kairos-expo-pivot-design.md` (in the studio commons). Working conventions: `AGENTS.md`.

```bash
npm install
npm run sync-tokens && npm run sync-fonts   # needs ../daoUI (or DAOUI_PATH)
npm start
```
